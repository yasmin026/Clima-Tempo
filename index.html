Configuração de API

Por padrão, este app utiliza um **Simulador de Dados Meteorológicos (Mock Data)** realista para você explorar o portfólio sem precisar cadastrar nada.

Se desejar dados 100% em tempo real da sua cidade, insira sua chave gratuita da **OpenWeatherMap API**:

Como obter uma chave gratuita?

1. Crie uma conta no site openweathermap.org.

2. Acesse a aba **API Keys** e copie sua chave gerada.
