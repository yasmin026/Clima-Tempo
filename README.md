# 🌤️ Atmosphere AI — Weather Analytics Dashboard

> Um dashboard meteorológico moderno e responsivo desenvolvido com foco em visualização de dados em tempo real, variação térmica com gráficos interativos e mapeamento geográfico.

---

## 🚀 Funcionalidades

* **Dados Meteorológicos Completos:** Exibição de temperatura atual, sensação térmica, umidade, velocidade do vento, pressão atmosférica e índice UV.
* **Gráficos Interativos (Chart.js):** Visualização clara da variação da temperatura ao longo das próximas 24 horas.
* **Mapa Interativo (Leaflet.js):** Localização geográfica em tempo real com mapa interativo estilizado em *Dark Theme*.
* **Previsão para 5 Dias:** Acompanhamento das condições do tempo e temperaturas máximas e mínimas para os próximos dias.
* **Alertas Meteorológicos:** Sistema de aviso visual para condições climáticas importantes (ex.: índice UV elevado).
* **Suporte a API Externa:** Integração pronta para a API oficial da OpenWeatherMap (com dados simulados no modo demonstração).
* **Alternância de Unidade:** Suporte para troca rápida entre Celsius (°C) e Fahrenheit (°F).

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com tecnologias front-end modernas e focadas em alto desempenho:

* **HTML5 Semantic**
* **Tailwind CSS** (estilização rápida e responsiva com efeitos de *Glassmorphism*)
* **JavaScript (ES6+)** (manipulação dinâmica do DOM, gestão de estado e chamadas de API)
* **Chart.js** (renderização de gráficos de linha)
* **Leaflet.js** (mapeamento interativo)
* **FontAwesome** (ícones modernos)
